# Historias de usuario

| ID | Historia de usuario |
|---|---|
| HU01 | Como Administrador del Sistema, quiero gestionar las cuentas de usuario y asignar los roles predefinidos, para controlar el acceso a las funcionalidades del sistema. |
| HU02 | Como Administrador del Sistema, quiero consultar la información de auditoría y seguridad, para supervisar las operaciones realizadas y mantener la trazabilidad del sistema. |
| HU03 | Como Responsable de Escalafón, quiero aperturar, buscar y consultar el legajo de un trabajador, para centralizar y localizar su información escalafonaria. |
| HU04 | Como Responsable de Escalafón, quiero registrar y mantener la información personal oficial y laboral del trabajador, para conservar su legajo actualizado y trazable. |
| HU05 | Como Responsable de Escalafón, quiero gestionar los vínculos laborales, contratos, adendas, asignaciones y movimientos del trabajador, para conservar su historial laboral de manera cronológica. |
| HU06 | Como Responsable de Escalafón, quiero registrar la formación académica, capacitaciones, méritos, deméritos y evaluaciones del trabajador, para mantener documentada su trayectoria institucional y profesional. |
| HU07 | Como Responsable de Escalafón, quiero gestionar los documentos sustentatorios asociados al legajo, para respaldar la información oficial registrada en el sistema. |
| HU08 | Como Trabajador municipal, quiero consultar únicamente mi propio legajo y los documentos habilitados para mí, para revisar la información oficial registrada sobre mi trayectoria. |
| HU09 | Como Trabajador municipal, quiero presentar solicitudes para registrar o actualizar mis datos personales permitidos, formación académica y capacitaciones, para mantener mi información actualizada sin modificar directamente los registros oficiales. |
| HU10 | Como Responsable de Escalafón, quiero revisar, aprobar o rechazar las solicitudes presentadas por los trabajadores, para controlar qué información propuesta se incorpora al legajo oficial. |
| HU11 | Como Responsable de Escalafón, quiero gestionar las unidades orgánicas y los catálogos configurables del sistema, para mantener actualizadas las referencias utilizadas en la gestión escalafonaria. |
| HU12 | Como Responsable de Escalafón, quiero consultar alertas sobre contratos y vínculos laborales próximos a vencer o vencidos, para realizar el seguimiento administrativo correspondiente. |
| HU13 | Como Responsable de Escalafón, quiero generar fichas escalafonarias y reportes autorizados del personal, para atender necesidades de consulta y gestión institucional. |
| HU14 | Como Usuario de Consulta Interna / Gerencia, quiero consultar dashboards, indicadores y reportes agregados, para apoyar la toma de decisiones sin acceder a información individual de los trabajadores. |
| HU15 | Como Responsable de Escalafón, quiero registrar locadores y sus servicios en un contexto separado del legajo escalafonario, para conservar información de referencia sin tratarlos como trabajadores con vínculo laboral. |
| HU16 | Como Responsable de Escalafón, quiero registrar la participación histórica de personal en inversiones, para conservar ese contexto sin convertirlo en un régimen o condición laboral. |
| HU17 | Como Responsable de Escalafón, quiero validar y confirmar la migración de la información existente en Excel antes de incorporarla al sistema, para reducir errores, resolver identidades y mantener la trazabilidad de la carga inicial. |
