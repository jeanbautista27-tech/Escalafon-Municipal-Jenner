# Historias de usuario

| ID | Historia |
|---|---|
| HU01 | Como administrador general, quiero gestionar los usuarios y sus permisos, para controlar el acceso a las funciones del sistema. |
| HU02 | Como administrador de escalafón, quiero registrar la ficha escalafonaria de cada trabajador, para centralizar su información laboral. |
| HU03 | Como administrador de escalafón, quiero actualizar la información de las fichas escalafonarias, para mantener vigentes los datos del personal. |
| HU04 | Como administrador de escalafón, quiero buscar y consultar la ficha de un trabajador, para encontrar rápidamente su información laboral. |
| HU05 | Como trabajador municipal, quiero consultar mi propia ficha escalafonaria, para conocer la información registrada sobre mi trayectoria laboral. |
| HU06 | Como administrador de escalafón, quiero registrar las plazas y asignaciones del personal por área y cargo, para controlar la distribución de los trabajadores. |
| HU07 | Como administrador de escalafón, quiero registrar las capacitaciones y certificaciones de los trabajadores, para mantener actualizada su trayectoria de formación. |
| HU08 | Como trabajador municipal, quiero consultar las capacitaciones y certificaciones registradas en mi ficha, para revisar mi historial de formación. |
| HU09 | Como administrador de escalafón, quiero generar reportes del personal por área, cargo y condición laboral, para apoyar la gestión y atender requerimientos institucionales. |
| HU10 | Como administrador de escalafón, quiero consultar alertas de trabajadores próximos a jubilarse, para anticipar la planificación administrativa del personal. |
